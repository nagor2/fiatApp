# Recharts Demo Gallery

Примеры всех типов графиков из библиотеки Recharts для DotFlat проекта.

## Использование

```javascript
import ChartsDemo from './demo/ChartsDemo';

// В вашем компоненте или роутере
<ChartsDemo />
```

## Типы графиков

1. **LineChart** - Линейные графики для цен токенов
2. **AreaChart** - Графики с заливкой для TVL
3. **BarChart** - Столбчатые диаграммы для объемов
4. **PieChart** - Круговые диаграммы для распределения активов
5. **RadarChart** - Радарные диаграммы для метрик
6. **ScatterChart** - Точечные графики для корреляций
7. **ComposedChart** - Комбинированные графики (линии + столбцы)
8. **CandlestickChart** - Свечные графики для торговли

## DeFi Use Cases

- **LineChart**: цена токена, APY, interest rate
- **AreaChart**: TVL (Total Value Locked), liquidity depth
- **BarChart**: trading volume, auction activity
- **PieChart**: asset allocation, collateral distribution
- **ComposedChart**: price + volume, reserves + transactions
- **CandlestickChart**: token price OHLC (если есть исторические данные)
